# Product Metrics

## Primary Objective

Maximize qualified interviews per application.

## KPIs

- Relevant Job Rate
- Response Rate
- Interview Rate
- Offer Rate
- Time To Apply
- ATS Match
- Applications per Interview
- Performance by Resume
- Performance by CandidateProfile
- Performance by JobSource
- Performance by Job Type
- Auto-apply False Positive Rate

Each metric must eventually be segmented by user where applicable and calculated from auditable lifecycle events rather than workflow execution counts alone.

## Quality Constraints

- duplicate applications = 0
- cross-user data leaks = 0
- invented CV facts = 0
- unsupported automatic submissions = 0

These constraints are release gates, not optimization targets that may be traded for application volume.
